# 📊 Result System

A simple **Result Management System** built using **PHP, MySQL, HTML, CSS, and JavaScript**.
It allows admin to manage student data and students to view their results.

---

## 🚀 Features

* Admin login
* Add students, subjects, and marks
* View student results
* Simple user interface

---

## 🛠️ Tech Stack

* HTML, CSS, JavaScript
* PHP
* MySQL (phpMyAdmin)
* XAMPP

---

## ⚙️ Setup (XAMPP)

1. Clone the repo:

   ```bash
   git clone https://github.com/gauravbashyal/result-system.git
   ```

2. Move it to:

   ```
   C:\xampp\htdocs\
   ```

3. Start **Apache** and **MySQL** in XAMPP

4. Open phpMyAdmin:

   ```
   http://localhost/phpmyadmin
   ```

5. Create database: `result_system`

6. Import SQL file from `/database`

7. Run:

   ```
   http://localhost/result-system
   ```
